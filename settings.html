🎬 视频导出设置

💡 视频设置说明：
  1. 转场动画类型：选择视频中步骤间的过渡效果
  2. 随机转场动画：每次导出时随机选择不同的转场效果
  3. 固定转场动画：所有步骤间使用相同的转场效果
  4. 每帧显示时长：每个步骤在视频中的显示时间
  5. 转场动画时长：步骤间过渡动画的持续时间

🖼️ 智谱视觉识别设置

启用智谱视觉识别
使用智谱 GLM-4.6V-Flash 模型对截图进行 AI 识别
支持多轮对话上下文，请描述您希望 AI 如何分析图片
💡 智谱视觉识别配置说明：
  1. 前往 智谱 AI 开放平台 注册并获取 API Key
  2. 支持的模型：GLM-4.6V-Flash（推荐，免费额度充足）
  3. 每次识别会消耗 API 调用额度，请注意使用
  4. 默认提示词可自定义，AI 会根据您的提示词分析图片
